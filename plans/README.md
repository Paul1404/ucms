- Break the site editor route into hooks and panels: real maintainability issue, but it should wait until save/publish ordering and server tests are in place.
- Replace repeated inspector list editors with typed repeatable-field primitives: useful cleanup, but lower leverage than registry consolidation.
- Untangle public canvas helpers from editor canvas: small cleanup, but not urgent.
- Render only the active public breakpoint: real performance opportunity, but it needs a careful SSR/no-flash design and is lower priority than data/security fixes.
- Avoid buffering S3 media through the app server: real performance opportunity, but media access semantics should be fixed first.
- Generate responsive image variants: valuable but larger than the current priority set.
- Cache CI dependencies and browser installs: useful DX cleanup, but lower priority than restoring typecheck.
- Regenerate Bun lockfile from manifest ranges: overlaps with 001; do it as part of dependency alignment if needed.
- Replace or isolate Playwright experimental CT: real migration risk, but defer until typecheck is restored and local CT prerequisites are documented.
- Track TanStack Start prerelease internals: keep as upgrade policy, not an immediate implementation plan.
